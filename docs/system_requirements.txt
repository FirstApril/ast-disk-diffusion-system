================================================================================
SYSTEM REQUIREMENTS & HARDWARE COMPATIBILITY REPORT
================================================================================
Target OS:      CachyOS (Arch Linux Base, x86-64-v3/v4 Optimized)
Target CPU:     Intel Core i5-14400F (10 Cores: 6P + 4E, 16 Threads)
Target RAM:     32 GB DDR4/DDR5
Target GPU:     AMD Radeon RX 9070 XT (16 GB VRAM)
Project Focus:  Antibiogram Analysis (YOLO Disc Detection & Zone Measurement)
================================================================================

1. HARDWARE COMPATIBILITY ANALYSIS
--------------------------------------------------------------------------------
- CPU (Core i5-14400F):
  Excellent multi-core performance for OpenCV preprocessing, image augmentation,
  and DataLoader multithreading (num_workers=8 to 12).
- RAM (32 GB):
  Optimal for caching high-resolution petri dish images in memory without OOM.
- GPU (Radeon RX 9070 XT with 16 GB VRAM):
  Ample VRAM for training YOLOv8/v9/v11 at imgsz=640 to 960 and Swin U-Net.
  Requires AMD ROCm (Radeon Open Compute) for PyTorch GPU acceleration.

2. SOFTWARE & DRIVER STACK (CACHYOS / ARCH LINUX)
--------------------------------------------------------------------------------
- Linux Kernel: CachyOS Kernel (BORE/EEVDF scheduler) 6.6+
- Compute Stack: rocm-hip-sdk, hip-runtime-amd, rocminfo
- Python Environment: Python 3.10 - 3.12 (Virtualenv recommended)
- Deep Learning: PyTorch ROCm 6.2+ (installed via ROCm wheel index)
- Vision Stack: ultralytics (YOLO), opencv-python, albumentations, timm

3. STEP-BY-STEP SETUP INSTRUCTIONS
--------------------------------------------------------------------------------
Step 1: Add user to render and video groups
  sudo usermod -a -G render,video $USER

Step 2: Install ROCm SDK on CachyOS
  sudo pacman -S --needed base-devel rocm-hip-sdk rocminfo hip-runtime-amd

Step 3: Setup Virtual Environment
  python3 -m venv venv
  source venv/bin/activate
  pip install --upgrade pip

Step 4: Install PyTorch with AMD ROCm support
  pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm6.2

Step 5: Install Python libraries
  pip install -r requirements.txt

Step 6: Hardware Environment Overrides (if required for new RDNA targets)
  export HSA_OVERRIDE_GFX_VERSION=11.0.0
  export HIP_VISIBLE_DEVICES=0

Step 7: Test ROCm GPU Acceleration
  python3 -c "import torch; print('ROCm Active:', torch.cuda.is_available()); print('Device:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'None')"
